# PrintCheck Android 3.4.0-alpha6

Продолжение Android-ветки PrintCheck для проверки макетов заказов Gifts.

## Alpha6

- версия 3.4.0-alpha6 указана и в интерфейсе, и в Android metadata;
- вход только через сайт gifts.ru; отдельной авторизации приложения нет;
- WebView показывается для входа, а обычная проверка заказа идёт со скрытым WebView в сохранённой сессии;
- управляющие кнопки выровнены и имеют одинаковую ширину;
- используются вкладки «Загрузка макетов» и «Шаблоны макетов» окна «Макеты для заказа»;
- конструктор связывается с артикулом по явной подписи во вкладке шаблонов;
- CDR игнорируются;
- PDF сравниваются по всем страницам в масштабе 1:1;
- перед техпроверкой из макета вычитается совпавшая графика конструктора, поэтому пунктирные служебные рамки не считаются нанесением;
- живой текст ищется только внутри фактического нанесения; текст конструктора и текст вне нанесения не считается ошибкой;
- проверяются тонкие позитивные и негативные элементы с текущим порогом 0,12 мм;
- позитивные проблемы отмечаются жёлтыми окружностями с толстой тёмной обводкой, негативные — голубыми;
- структурные PDF-признаки Shading, SMask/alpha и blend mode сопоставляются с визуальным анализом области нанесения;
- добавлена эвристика для уже растрированных плавных переходов и мягких эффектов;
- результат сохраняется в result.json, трассировка — в matching_trace.jsonl, маркированные изображения — в technical/*.png.

## Принцип проверки

Технические требования применяются не ко всему листу PDF, а к найденной области нанесения после вычитания конструктора. Это сделано специально, чтобы служебные подписи, шрифты и пунктирные рамки шаблона не давали ложных ошибок.

GitHub Actions собирает debug APK workflow-файлом .github/workflows/android.yml.
