# PrintCheck Android 3.0.0-alpha1

Первая нативная Android-ветка для тестирования непосредственно на телефоне.

## Что уже перенесено

- авторизация gifts.ru внутри WebView; cookies сохраняет Android WebView;
- ввод только номера заказа;
- открытие заказа и окна «Макеты для заказа»;
- вкладка/DOM «Загрузка макетов»: скачиваются PDF-макеты;
- вкладка/DOM «Шаблоны макетов»: читается **явная связь артикул → PDF-конструктор**;
- CDR полностью игнорируются и не скачиваются;
- скачивание выполняется с cookies той же авторизованной WebView-сессии;
- каждый PDF разбирается на **все страницы**;
- приложение не считает «1 PDF = 1 макет»;
- каждая страница сравнивается с каждым конструктором, и на странице может быть найдено несколько независимых вхождений конструктора;
- сравнение идёт только в масштабе 1:1: одинаковые физические PDF-размеры при одинаковом DPI;
- подробная трассировка каждого сравнения в `matching_trace.jsonl`;
- `result.json` содержит все обнаруженные отдельные макеты/вхождения.

## Почему Android-алгоритм немного отличается от Windows

На Android используется `PdfRenderer`, который гарантированно есть в системе, поэтому текущий тестовый matcher сравнивает растеризованную геометрию. Он строит связанные компоненты, 8×8 сигнатуры формы и голосование за единый сдвиг конструктора внутри макета. Масштабирование конструктора для получения совпадения запрещено.

Это специально сделано без внешних PDF-библиотек, чтобы приложение можно было собрать без тяжёлого Python-runtime.

## Сборка APK

Проект открывается в Android Studio. Требования: Android SDK 35, JDK 17+. Сборка: `Build > Build APK(s)`.

В репозитории есть `.github/workflows/android.yml`, который собирает debug APK автоматически в GitHub Actions.

## Что тестировать первым

Заказ `7920509`:
1. должны загрузиться 9 PDF-макетов и 7 PDF-конструкторов;
2. в «Шаблон → артикул» должны быть полные артикулы, например `17488.30`, а не `17488`;
3. `7920509_maket_8_160926_102801.pdf` должен найти `15637_1.pdf → арт. 15637`;
4. обработка обязана пройти **все PDF и все страницы**;
5. если на странице несколько макетов, в «Сопоставления» должно быть несколько отдельных строк.

## Следующий этап разработки

После подтверждения правильного распределения на Android добавляется вычитание конструктора/служебной графики и техническая проверка каждого найденного нанесения.
